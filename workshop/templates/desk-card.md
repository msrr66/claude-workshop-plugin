# بطاقة المكتب (تُطبع وتُغلَّف — وجهان)

## الوجه الأول — العادات الأربع
1. **موضوع جديد = محادثة جديدة.** Claude يعيد قراءة المحادثة كلها كل مرة.
2. **اترك الإعدادات كما هي.** (توفير الحصة درس المستوى الثاني.)
3. **وضّح قبل أن تنفّذ.** الهدف، الجمهور، القيود، شكل المخرج.
4. **تحقق قبل أن تثق.** الرقم بلا مصدر «غير مدعوم». الثقة المعلنة ليست تحققًا.

## الوجه الثاني — المسار الواحد
موجز → ملفات → تقطير → ملف نهائي → مراسلة → فحص → تفويض → استشارة → إصلاح

**القاعدة الذهبية:** اذكر اسم المهارة صراحة بالعربي: «**استخدم مهارة** راجع النتيجة».

| أريد | أقول |
|---|---|
| طلب واضح | استخدم مهارة وضّح أولًا |
| يكلّمك باللهجة | استخدم مهارة صوتي السعودي |
| ملخص قرار من ملف | استخدم مهارة لخّص المستند |
| ملف Word/PowerPoint/Excel | استخدم مهارة صانع الملفات |
| إيميل أو خطاب بصوتك | استخدم مهارة كاتب المراسلات |
| فحص المخرج | استخدم مهارة راجع النتيجة |
| مهمة متعددة الخطوات | استخدم مهارة وكيل |
| قرار | استخدم مهارة استشارة |
| إصلاح نقطة واحدة | «أصلح هذا فقط، ولا تغيّر غيره» |
| إنهاء المحادثة | استخدم مهارة أغلق الجلسة |

**الأمان:** لا بطاقات، لا كلمات مرور، لا بيانات عملاء حساسة. قبل تثبيت مهارة من الإنترنت: لا إرسال بيانات، لا روابط غريبة، لا سكربتات غير مشروحة.
