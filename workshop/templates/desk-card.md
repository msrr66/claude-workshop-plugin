# بطاقة المكتب (تُطبع وتُغلَّف — وجهان)

## الوجه الأول — العادات الأربع
1. **موضوع جديد = محادثة جديدة.** Claude يعيد قراءة المحادثة كلها كل مرة.
2. **الإعدادات الثلاثة:** النموذج الأصغر للبسيط · الجهد الأقل · التفكير الممتد مطفأ إلا للصعب.
3. **وضّح قبل أن تنفّذ.** الهدف، الجمهور، القيود، شكل المخرج.
4. **تحقق قبل أن تثق.** الرقم بلا مصدر «غير مدعوم». الثقة المعلنة ليست تحققًا.

## الوجه الثاني — المسار الواحد
موجز → ملفات → تقطير → ملف نهائي → مراسلة → فحص → تفويض → استشارة → إصلاح

**القاعدة الذهبية:** اذكر اسم المهارة صراحة: «**استخدم مهارة** compare-to-brief …». الاسم العربي وحده قد لا يفعّلها.

| أريد | أقول |
|---|---|
| طلب واضح | استخدم مهارة clarify-first |
| ملخص قرار من ملف | استخدم مهارة document-distiller |
| ملف Word/PowerPoint/Excel | استخدم مهارة deliverable-maker |
| إيميل أو خطاب بصوتي | استخدم مهارة my-voice-correspondence |
| فحص المخرج | استخدم مهارة compare-to-brief |
| مهمة متعددة الخطوات | استخدم مهارة wakeel-lite |
| قرار | استخدم مهارة consult-lite |
| إصلاح نقطة واحدة | «أصلح هذا فقط، ولا تغيّر غيره» |
| إنهاء المحادثة | استخدم مهارة session-closer |

**الأمان:** لا بطاقات، لا كلمات مرور، لا بيانات عملاء حساسة. قبل تثبيت مهارة من الإنترنت: لا إرسال بيانات، لا روابط غريبة، لا سكربتات غير مشروحة.
