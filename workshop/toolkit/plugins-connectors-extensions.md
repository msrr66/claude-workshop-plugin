# الإضافات والموصلات والامتدادات — قائمة التجهيز بحسب الفئة

كلها تحتاج خطة **Pro** (الموصلات وحدها تعمل على المجاني). المصادر في research/T03.

## 1. الإضافات (Plugins) — Customize > Plugins > Discover > Install
التثبيت لا يربط الموصلات المضمّنة؛ افتح تبويب **Connectors** داخل الإضافة وسجّل كل موصل.

| فئتك | ثبّت | ماذا يعطيك |
|---|---|---|
| صاحب منشأة / عمل حر | **small-business** | 44 مهارة: متابعة الفواتير، لقطة التدفق النقدي، بناء العروض، محتوى السوشيال، السمعة والتقييمات، توظيف… ويعمل من CSV أو بريد ملصوق |
| موظف | **productivity** | المهام، التقويم، الملخص اليومي، فك اختصارات شغلك |
| تسويق | **marketing** | المحتوى، الحملات، مراجعة الهوية، المنافسين |
| طالب / خريج | **productivity** + **product-management** | التنظيم، المواصفات، التحديثات للجهات |
| الجميع (اختياري) | **customer-support** إن كنت ترد على عملاء | فرز الطلبات، صياغة الردود |

لا تثبّت أكثر من إضافتين في البداية؛ الإضافات تزيد استهلاك الحصة.

## 2. الموصلات (Connectors) — في أي محادثة: + > Connectors > Manage > +
| الموصل | لمن | ماذا تطلب بعده |
|---|---|---|
| **Google Drive** | الجميع (مربوط قبل الورشة) | «لخّص ملف ___ من Drive» |
| **Gmail** | الجميع | «لخّص آخر 5 رسائل من ___ وجهّز ردًا» — الإرسال بموافقتك |
| **Google Calendar** | الجميع | «متى عندي فراغ ساعة هذا الأسبوع؟» |
| **Canva** | أصحاب الأعمال والتسويق | «صمّم منشورًا بعرض اليوم» |
| **Notion / Slack / Asana** | من يستخدمها أصلًا | — |
| **Microsoft 365** | موظفو الشركات بحساب عمل فقط | يحتاج موافقة مدير النظام؛ ليس في القاعة |

استخدم **حساب Google شخصيًا**؛ حسابات الشركات قد تُحظر.

## 3. الامتدادات والتطبيقات
| الأداة | كيف | ماذا تجرّب |
|---|---|---|
| **Claude in Chrome** (Pro) | من claude.ai/download أو متجر كروم | افتح صفحة منتج/مقال واطلب: «لخّص هذه الصفحة واستخرج الأسعار» |
| **تطبيق الجوال** | المتجر | المحادثة الصوتية؛ تصوير مستند وتلخيصه |
| **تطبيق سطح المكتب + Cowork** | مثبّت قبل الورشة | العمل على مجلداتك |

## 4. الإعدادات التي تُضبط مرة واحدة
- Settings > Capabilities > **Cloud code execution and file creation** (مطلوب للمهارات والملفات).
- Settings > **Memory**: راجع ما يتذكره عنك وعدّله.
- Settings > Profile: الملف الشخصي (قالب الحقيبة).
- الإعدادات الثلاثة في كل محادثة: النموذج، الجهد، التفكير الممتد.

## 5. قاعدة الأمان قبل أي تثبيت من الإنترنت
لا مهارة أو إضافة ترسل بياناتك لمكان مجهول · لا روابط غريبة · لا سكربتات غير مشروحة. والأفضل: ثبّت من دليل Anthropic الرسمي (Discover) أولًا.
