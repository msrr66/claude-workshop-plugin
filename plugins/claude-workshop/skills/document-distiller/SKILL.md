description: Use when the user uploads or pastes a PDF, Excel, Word, or long text and asks to summarize, extract key points, "لخّص", "قطّر", or "ما المهم في هذا الملف". Produces a fixed four-column table (key numbers, risks, decisions needed, actions with owner and date) plus 3 open questions, with every number citing its source page or line. Do not use for short messages or when the user wants a rewrite rather than a distillation.

# مُلخّص المستندات

## متى تُفعَّل
عند طلب تلخيص أو استخلاص المهم من ملف (PDF، Excel، Word) أو نص يتجاوز صفحة.

## الخطوات
1. اقرأ الملف كاملًا قبل أي كتابة. إن كان Excel افحص كل الأوراق (Sheets) وقل أسماءها.
2. اجمع **الأرقام المهمة** فقط: مبالغ، نسب، مواعيد، كميات تؤثر في قرار. كل رقم بجانبه مصدره: (ص 3) أو (ورقة «المبيعات» صف 12) أو (سطر 40).
3. اجمع **المخاطر**: ما قد يسبب خسارة أو تأخيرًا أو مخالفة، مع المصدر.
4. اجمع **القرارات المطلوبة**: ما ينتظر قرار القارئ، صيغته سؤال واضح.
5. اجمع **الإجراءات**: فعل + مسؤول + موعد. إن لم يذكر الملف مسؤولًا أو موعدًا اكتب «غير محدد في الملف» ولا تخترع.
6. اختم بـ **3 أسئلة مفتوحة** لم يجب عنها الملف ويحتاجها القارئ ليقرر.
7. إن تعارض رقمان في الملف اذكر الاثنين ومصدريهما ولا ترجّح بصمت.

## شكل المخرج
```
الملف: [الاسم] — [عدد الصفحات/الأوراق] — قُرئ كاملًا: نعم/جزئيًا (السبب)

| البند | التفصيل | المصدر |
|---|---|---|
| الأرقام المهمة | ... | ص/ورقة/سطر |
| المخاطر | ... | ... |
| القرارات المطلوبة | ... | ... |
| الإجراءات (مسؤول + موعد) | ... | ... |

أسئلة مفتوحة:
1. ... 2. ... 3. ...
```

## ممنوعات
- لا رقم بلا مصدر. إن لم تجد المصدر فلا تذكر الرقم، أو اكتبه مع «غير مدعوم».
- لا تلخّص ملفًا لم تستطع قراءته كاملًا دون أن تقول ذلك في السطر الأول.
- لا تضف رأيًا أو توصية داخل الجدول؛ الجدول حقائق من الملف فقط.
- لا تجمع أرقامًا حسابيًا من رأسك؛ إن احتجت مجموعًا احسبه بأداة الكود وقل «محسوب».

## مثال قصير
```
الملف: عرض سعر المقاول.pdf — 4 صفحات — قُرئ كاملًا: نعم
| الأرقام المهمة | الإجمالي 184,000 ريال شامل الضريبة؛ الدفعة المقدمة 40% | ص 2، ص 3 |
| المخاطر | لا بند غرامة تأخير؛ مدة التنفيذ «تقريبًا 60 يومًا» | ص 3 |
| القرارات المطلوبة | هل نقبل دفعة مقدمة 40% أم نفاوض على 25%؟ | ص 3 |
| الإجراءات | توقيع العرض — المسؤول: غير محدد في الملف — قبل 1446/11/30 | ص 4 |
أسئلة مفتوحة: 1. هل السعر يشمل التوريد؟ 2. من يتحمل رسوم البلدية؟ 3. ما مرجع «تقريبًا 60 يومًا»؟
```
